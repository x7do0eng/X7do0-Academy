# Project Vision — X7do0 Academy

## Mission

X7do0 Academy exists to teach programming and computer engineering concepts with depth, clarity, and minimalism. The focus is on fundamental understanding — the "why" behind the syntax — rather than surface-level tutorial content.

## Current State

- **Live course:** Python Core (12 lessons, 25 practice questions).
- **Platform:** Static website deployed on GitHub Pages.
- **Language support:** English and Arabic (bilingual).
- **Theme support:** Light and dark modes.
- **Testing:** Playwright E2E tests for critical paths.

## Future Direction

Planned courses in priority order:
1. **Python Core** — Active and growing.
2. **C++ Systems** — Memory management, performance, systems programming.
3. **C#** — Modern application development.
4. **AI / ML** — Machine learning and artificial intelligence fundamentals.
5. **Additional engineering content** — Data structures, algorithms, system design.

## Design Philosophy

- **Minimalism.** Clean layouts, focused content, no distractions.
- **Depth over breadth.** Teach concepts thoroughly, not superficially.
- **Accessibility.** Every page, every feature must work for all learners.
- **Bilingual by default.** English and Arabic are first-class citizens, not afterthoughts.
- **Mobile-first.** Learning happens everywhere.

## Technical Philosophy

- **No framework lock-in.** This site uses vanilla HTML/CSS/JS to remain lightweight and maintainable for decades.
- **Static deployment.** GitHub Pages means zero server costs and infinite scaling.
- **Tested evolution.** Playwright ensures that changes don't break existing functionality.
- **Documented decisions.** Architecture decisions are recorded in `docs/` for future maintainers.
